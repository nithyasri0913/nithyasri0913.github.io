# Academic Research Portfolio

A clean, professional portfolio website for academics and researchers, featuring a dark theme with black background and white text.

## Features

- Responsive design (mobile & desktop)
- Dark theme (black background, white text)
- Smooth scrolling navigation
- Fade-in animations
- Standard academic sections: About, Research, Publications, CV, Contact

## Files

- `index.html` - Main HTML structure
- `style.css` - All styling (dark theme)
- `script.js` - Interactive features and animations
- `profile-photo.jpg` - Your profile picture (you need to add this)
- `CV.pdf` - Your CV file (you need to add this)

## Setup Instructions

### 1. Customize Your Content

Edit `index.html` and replace:
- "Your Name" with your actual name
- "PhD Candidate / Research Position Title" with your position
- "Department • University Name" with your affiliation
- Fill in your bio, research interests, projects, and publications
- Update contact information and social media links

### 2. Add Your Files

- Add your profile photo as `profile-photo.jpg`
- Add your CV as `CV.pdf`

### 3. Deploy to GitHub Pages

#### Option A: New Repository
1. Create a new repository on GitHub named `username.github.io` (replace "username" with your GitHub username)
2. Upload all files to this repository
3. Your site will automatically be available at `https://username.github.io`

#### Option B: Project Repository
1. Create a new repository with any name (e.g., "portfolio")
2. Upload all files to this repository
3. Go to Settings → Pages
4. Under "Source", select "main" branch and "/" (root) folder
5. Click Save
6. Your site will be available at `https://username.github.io/portfolio`

### 4. Custom Domain (Optional)

If you want a custom domain (e.g., yourname.com):
1. Buy a domain from any registrar
2. In your GitHub repository, go to Settings → Pages
3. Add your custom domain
4. Configure your domain's DNS settings (follow GitHub's instructions)

## Customization

### Colors
To change the color scheme, edit `style.css`:
- Background: `#000000` (black)
- Text: `#ffffff` (white)
- Accents: `#cccccc`, `#aaaaaa` (grays)

### Fonts
Current font: Georgia (serif)
To change, edit the `font-family` in `style.css`

### Sections
To add/remove sections:
1. Edit `index.html` to add/remove `<section>` elements
2. Update navigation links in `<nav>`
